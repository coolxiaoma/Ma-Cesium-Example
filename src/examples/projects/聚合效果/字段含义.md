# 水库 mock 数据字段含义

## 基础信息

| 字段 | 含义 |
|------|------|
| `id` | 唯一编号 |
| `code` | 水库编码（业务唯一标识） |
| `name` | 水库正式名称 |
| `alias` | 别名 / 俗称 |
| `status` | 运行状态（如：运行中、检修、停运） |
| `remark` | 备注说明 |

## 位置信息

| 字段 | 含义 |
|------|------|
| `longitude` | 经度（WGS84） |
| `latitude` | 纬度（WGS84） |
| `altitude` | 海拔高程（米），一般对应正常蓄水位附近坝顶/水面高程 |
| `province` | 所在省（自治区、直辖市） |
| `city` | 所在市（州） |
| `county` | 所在区 / 县 |

## 水系信息

| 字段 | 含义 |
|------|------|
| `basin` | 所属流域（如长江流域、黄河流域） |
| `river` | 所在河流 / 支流名称 |

## 工程属性

| 字段 | 含义 |
|------|------|
| `level` | 工程规模等级：大型 / 中型 / 小型 |
| `type` | 水库类型（综合利用、防洪灌溉、供水、发电等） |
| `function` | 主要功能列表（防洪、供水、灌溉、发电、航运、旅游等） |
| `damHeight` | 坝高（米） |
| `damLength` | 坝长（米） |
| `buildYear` | 开工年份 |
| `completionYear` | 建成 / 竣工年份 |

## 库容（单位：亿立方米）

| 字段 | 含义 |
|------|------|
| `totalCapacity` | 总库容 |
| `beneficialCapacity` | 兴利库容（可供调节利用的库容） |
| `deadCapacity` | 死库容（死水位以下、不可动用的库容） |
| `floodControlCapacity` | 防洪库容（用于拦蓄洪水的库容） |
| `currentStorage` | 当前蓄水量 |

## 水位（单位：米）

| 字段 | 含义 |
|------|------|
| `waterLevel` | 当前水位 |
| `normalWaterLevel` | 正常蓄水位（正常运用时允许达到的最高水位） |
| `floodLimitLevel` | 汛限水位（汛期限制蓄水的水位） |
| `deadWaterLevel` | 死水位（允许消落到的最低水位） |

## 效益指标

| 字段 | 含义 |
|------|------|
| `catchmentArea` | 集水面积 / 流域面积（平方公里） |
| `irrigatedArea` | 设计灌溉面积（万亩） |
| `installedCapacity` | 装机容量（万千瓦），无电站为 `0` |

## 管理与安全

| 字段 | 含义 |
|------|------|
| `managementUnit` | 管理单位名称 |
| `contactPhone` | 联系电话 |
| `riskLevel` | 风险等级：低 / 中 / 高 |
| `lastInspectionDate` | 最近一次巡检 / 检查日期 |
